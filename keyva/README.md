# Keyva v2 — A logbook that knows what time it is

Local-first, no account, three-tense architecture (done / planned / list).

## Quickstart

```bash
flutter pub get
dart run build_runner build
flutter test test/corpus_test.dart
flutter run
```

## Documentation
- `NOTES.md`: Architecture overview, Schema v2, parsing, and build notes.
- `WIDGET_SETUP.md`: Native Android widget configuration, quick capture floating card, and background receiver details.
